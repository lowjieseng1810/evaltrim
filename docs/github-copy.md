## Long description

EvalTrim is a local-first CLI for AI-agent evaluation suites. It grades and compares runs, then maintains the suite itself: unique behavioral witnesses, counterfactual removal, suite health, and KEEP / MERGE / REVIEW / RETIRE recommendations with an evidence ledger. It never deletes tests.
